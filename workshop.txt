title=Vehicle Finder
description=[h1]Vehicle Finder[/h1]
description=[b]Find your favourite car.[/b]
description=
description=A small floating car button — drag it anywhere, or hide it and use the hotkey — opens a searchable list of every vehicle loaded around you: name, colour, distance, compass direction and map coordinates, nearest first. Click a row to track a vehicle and the button itself shows a direction pip and the live distance while you walk, even with the window closed.
description=
description=[h1]Features[/h1]
description=[list]
description=[*] [b]Floating car button[/b] — drag it anywhere, resize it (32–56 px), or hide it entirely and use the hotkey. Its position is remembered.
description=[*] [b]Searchable vehicle list[/b] — filter by name, sorted nearest first, with colour swatch, distance, compass direction and map coordinates on every row.
description=[*] [b]Tracking[/b] — click a row and the button points at that vehicle and counts down the distance, window open or closed.
description=[*] [b]Double-click to jump[/b] — tracks the vehicle [i]and[/i] opens the world map centred on it.
description=[*] [b]Dots on the world map[/b] — open the map (M) and vehicles appear as dots: filled for loaded, hollow for remembered, amber and named for the one you track.
description=[*] [b]"All known" range[/b] — every vehicle that has ever come into range is remembered with its coordinates and how long ago it was seen, so you can find the pickup you passed two days ago.
description=[*] [b]Hide burnt wrecks[/b] — one click in the window, no new world needed. Also available as a sandbox option.
description=[*] [b]Modded vehicle support[/b] — cars from other mods show a readable name even without a translation, and are marked with *.
description=[*] [b]Rebindable hotkey[/b] — F8 by default, changed in Options > Key bindings. Ignored while you are typing in chat or in the search box.
description=[/list]
description=
description=[h1]Why you might want it[/h1]
description=[list]
description=[*] [b]Patches nothing.[/b] No vanilla Lua file is required, replaced or overridden — so it does not fight with other UI or vehicle mods, and it does not break every time Build 42 updates.
description=[*] [b]One global only.[/b] Everything lives inside a single [i]VehicleFinder[/i] namespace.
description=[*] [b]Polite about screen space.[/b] On first run the button probes for a free slot instead of landing on another mod's HUD, and the hotkey is registered without stealing another mod's binding.
description=[*] [b]Fails soft.[/b] Every call into the game API is wrapped: if a future build renames something, that one feature goes quiet instead of taking the UI down with it.
description=[*] [b]Clean saves.[/b] UI settings live in their own ini file, not in your save; the sighting history lives in that world's save data and is deleted with it. Nothing leaks between saves.
description=[/list]
description=
description=[h1]Honest limitations[/h1]
description=[list]
description=[*] [b]It can only see loaded chunks.[/b] A vehicle exists as an object only while the game has its chunk loaded — roughly the area around you. Lua cannot read vehicles out of a save file that has not been loaded, so no mod can truly scan the whole map live. "All known" works around this by remembering, not by reaching further.
description=[*] [b]Remembered coordinates can go stale.[/b] If a car has been moved since you last saw it, the stored position is where it [i]was[/i]. Every history row shows the sighting age (2d, 5h) so you can judge it.
description=[*] [b]Map dots need a pen.[/b] You have to be carrying a pen or pencil, the same rule vanilla uses for writing on the map. Without one there are no dots, and the window tells you why.
description=[*] [b]History is capped at 500 entries[/b], oldest sightings dropped first.
description=[*] [b]Multiplayer history is session-only.[/b] The mod works in MP, but the history table is server-global data, so there it is kept in memory for the session rather than saved.
description=[*] [b]Build 42 only.[/b] The mod uses the B42 folder structure and will not load on Build 41.
description=[/list]
description=
description=[h1]Compatibility[/h1]
description=Safe to add to an existing save, and safe to remove — nothing it writes is required by the world. Works alongside vehicle mods such as Filibuster Rhymes' Used Cars and Autotsar Trailers.
